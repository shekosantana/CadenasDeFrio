# Cadenas de Frío

Sistema IoT para el monitoreo y diagnóstico de condiciones en cadenas de frío.

## Integrantes

- Sergio Daniel Santana Nuñez
- Christian Arturo Flores Diaz

## Sensores

- DHT11: temperatura y humedad
- DS18B20: temperatura
- Sensor magnético: estado de la puerta

## Hardware

- ESP32
- Protoboard
- Sensores de temperatura, humedad y puerta
